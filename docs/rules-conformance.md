# 规则一致性审计

本文记录“忍神控制台”对《忍术战斗 RPG 忍神》十周年改订版基础规则的实现边界。它是开发与回归测试清单，不是规则书替代品；不收录完整规则正文、忍法表或官方模组内容。

## 权威顺序

发生冲突时按以下顺序处理：

1. 冒险企划局当前官方勘误与 FAQ；
2. 日文十周年改订版规则书；
3. 本地持有的简中 v1.51 译本（界面中文术语以其为基准；规则语义冲突时以上两项优先）；
4. BCDice 的当前 ShinobiGami 命令实现；
5. 用户本地持有的自动角色卡导出数据。

自动角色卡导出数据适合核对字段与编号格式，但包含非官方的整理与解释，因此不作为最终规则依据。

## 已自动执行的基础规则

| 模块 | 当前实现 | 回归检查 |
| --- | --- | --- |
| 特技距离 | 目标值为 `5 + 距离`，分野间空隙与涂黑空隙分别计算 | 有 |
| 代用特技 | 默认提示最近特技，也允许玩家主动选择更远的已习得特技 | 有 |
| 无可用特技 | 不把目标值伪装成 12；普通结果不能成功，只保留大成功成功 | 有 |
| 特殊骰点 | 大成功、大失败先看修正前骰点；修正只改变达成值 | 有 |
| 大失败窗口 | 通常为 2；剧情场景使用支援忍法时按 2＋花费抬升（判定面板「支援忍法花费」输入）；战斗从攻击处理至回合结束改用布局值并产生逆止；大失败值上限 11 | 有 |
| BCDice 命令 | 使用 `nSG@s#f>=x`，多骰时取最高两颗 | 有 |
| 距离与花费 | 忍法距离按布局差检查；同回合累计花费不得超过布局值；布局时使用支援忍法允许超出（合计不足 7，界面放行并提示本回合禁再用带花费忍法）；同名攻击／支援忍法一回合一次 | 有 |
| 情报共享 | 对直接获得情报的角色抱有感情者自动获得；共享不会继续连锁 | 有 |
| 感情修正 | 正面固定 +1、负面固定 −1；剧情场景每巡一次／战斗每回合一次；同一持有者的复数感情整体加锁 | 有 |
| 感情与变调名 | 采用简中 v1.51 译名：感情表首对“共鸣／猜疑”、变调“忘却”“行踪不明”等 | 有 |
| 旧存档迁移 | 移除旧版误存的“感情修正”伪忍法；“失忆”→“忘却”；特技旧名“掘削术／色诱术／千里眼术”自动迁移为 v1.51 译名“挖掘术／女忍术／千里眼之术” | 有 |

## 由界面引导、仍由 GM 确认的规则

- 大成功后的生命力或变调回复、命中大成功的追加伤害；
- 神通丸、遁甲符等重投的宣言顺序与连续重投；
- 复数目标、同一布局的同时处理及同一时机效果顺序（同速批次的伤害／逆止／变调由界面暂缓并提示，待全员完成攻击处理后由 GM 统一点选应用）；
- 接近战、射击战、集团战伤害的实际分野或变调选择；
- 感情判定成功后，双方分别掷感情表并各自决定正面或负面；
- 「麻痹」变调封锁的具体特技（随机选定与累积由 GM 记录，判定面板暂不自动剔除）；
- 【木莲】【魔界工学】带来的特技表上下／左右连通（距离计算需 GM 手动修正目标值）；
- 布局值 0 的角色（一般人等）：界面布局仅支持 1–6，此类角色的距离豁免与大失败值按规则书由 GM 处理；
- 感情战斗乱入的资格（仅限对最初两名参战者抱有感情）与宣言时机；
- 胜者、战果、脱落、奥义破解，以及各忍法或背景的特殊文本。

这些流程会显示检查点和日志，但不会在缺少完整效果文本时擅自替 GM 作出选择。

## 不在“一致性保证”内的内容

- 用户自行录入的自定义忍法、背景、奥义与模组特殊规则；
- 自动 Replay、场景牌桌、局势神谕和“失败也前进”建议；
- 自动角色卡作者 QA 中没有得到官方规则或勘误支持的解释；
- 扩展书全部忍法效果的自动结算。

以上功能都不会暗中修改真实骰点、判定结果、伤害或秘密。界面中的原创主持建议会明确标为灵感或自定义处理。
