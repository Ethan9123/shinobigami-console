# 规则一致性审计

本文记录“忍神控制台”对《忍术战斗 RPG 忍神》十周年改订版基础规则的实现边界。它是开发与回归测试清单，不是规则书替代品；不收录完整规则正文、忍法表或官方模组内容。

## 权威顺序

发生冲突时按以下顺序处理：

1. 冒险企划局当前官方勘误与 FAQ；
2. 日文十周年改订版规则书；
3. 本地持有的简中 v1.51 译本（界面中文术语以其为基准；规则语义冲突时以上两项优先）；
4. BCDice 的当前 ShinobiGami 命令实现；
5. 用户本地持有的自动角色卡导出数据。

自动角色卡导出数据适合核对字段与编号格式，但包含非官方的整理与解释，因此不作为最终规则依据。

## 已自动执行的基础规则

| 模块 | 当前实现 | 回归检查 |
| --- | --- | --- |
| 特技距离 | 目标值为 `5 + 距离`，分野间空隙与涂黑空隙分别计算（`skillDistance` 兼容旧的空隙数组，也接受 `SkillTableOptions`） | 有 |
| 【木莲】【魔界工学】 | 两条装备忍法收录为机制数据；习得【木莲】时特技表最上一行与最下一行相邻，习得【魔界工学】时器术列与妖术列相邻，器术左侧外空隙（`Character.outerGapClosed`）只在左右连通时计入；开关由已习得忍法推出（`skillTableOptions`，同名自定义忍法也认），代用取较短的一侧并在判定面板注明经由连通；BCDice 调色板与 Foundry 目标值同步，Foundry `gap["0"]` 写入外空隙 | 有 |
| 麻痹 | 每追加一层就从尚未被封的已习得特技中随机封锁 1 个（`applyParalysis`，可累积到已习得特技数），`Character.paralyzedSkills` 记录被封特技，「麻痹」标签由它派生；判定面板与 BCDice 调色板用同一个 `usableSkills` 剔除失去生命力分野与被封的特技；「全部解除」对应巡末《身体操术》判定成功；旧档只有标签时提示补抽，载入时不随机 | 有 |
| 得意分野 | 六大流派及其下位流派按得意分野检查：特技数不足（六大流派 3 个、下位流派 2 个）给出 `specialty-skills` 提醒，空隙与建议不一致给出 `specialty-gaps` 提醒（长处背景可能改变空隙，因此只提醒、不阻塞、不自动覆盖）；角色工作台可一键按建议涂黑；原创流派不做建议 | 有 |
| 代用特技 | 默认提示最近特技，也允许玩家主动选择更远的已习得特技 | 有 |
| 无可用特技 | 不把目标值伪装成 12；普通结果不能成功，只保留大成功成功 | 有 |
| 特殊骰点 | 大成功、大失败先看修正前骰点；修正只改变达成值 | 有 |
| 大失败窗口 | 通常为 2；剧情场景使用支援忍法时按 2＋花费抬升（判定面板「支援忍法花费」输入）；战斗从攻击处理至回合结束改用布局值并产生逆止；大失败值上限 11 | 有 |
| BCDice 命令 | 使用 `nSG@s#f>=x`，多骰时取最高两颗 | 有 |
| 距离与花费 | 忍法距离按布局差检查；同回合累计花费不得超过布局值；布局时使用支援忍法允许超出（合计不足 7，界面放行并提示本回合禁再用带花费忍法）；同名攻击／支援忍法一回合一次 | 有 |
| 攻击时机 | 攻击忍法只能在布局公开后、轮到自己行动时宣言，且一回合一次（`canDeclareAttack`）；支援忍法不受此限；追加攻击等特例由宣言面板的「GM 覆盖」开关放行并写入日志 | 有 |
| 「自由」指定特技 | 【接近战攻击】【射击战攻击】等指定特技为「自由」的忍法，习得时须选定 1 个特技（`Character.ninpoSkills`）；未指定时拒绝宣言、开团门禁给出 `free-skill-unset` 阻塞并附一键建议；宣言时把实际特技写入结算（`Resolution.designatedSkill`），命中判定与回避判定都锚定到该特技，不再沿用判定面板的残留特技；BCDice 调色板与 Foundry 导出使用解析后的特技；自定义忍法可选「自由／无」 | 有 |
| 逆止 | 陷入逆止的角色进行行为判定时自动失败、达成值视为 0，成功率显示 0%；奥义或写明可在逆止中使用的忍法可在判定面板勾选豁免；新回合开始时解除 | 有 |
| 布局值 0 | 布局栏提供「违规→0」；布局 0 的角色行动排在最后、大失败值为 2；布局 1 以上的角色以其为目标时无视距离（日志注明） | 有 |
| 判定面板复位 | 宣言忍法、进入回避、切换行动者、开始新回合或切换选中角色时，代用选择、修正、骰池、支援花费与逆止豁免全部复位，不会串用到下一人的判定 | 有 |
| 情报共享 | 对直接获得情报的角色抱有感情者自动获得；共享不会继续连锁 | 有 |
| 感情修正 | 正面固定 +1、负面固定 −1；剧情场景每巡一次／战斗每回合一次；同一持有者的复数感情整体加锁 | 有 |
| 感情与变调名 | 采用简中 v1.51 译名：感情表首对“共鸣／猜疑”、变调“忘却”“行踪不明”等 | 有 |
| 旧存档迁移 | 移除旧版误存的“感情修正”伪忍法；“失忆”→“忘却”；特技旧名“掘削术／色诱术／千里眼术”自动迁移为 v1.51 译名“挖掘术／女忍术／千里眼之术”；存档 schema 9 新增 `ninpoSkills`（旧档留空、不猜测，由开团门禁或宣言时提示补选）、`paralyzedSkills`（只保留已习得特技、去重并迁移旧名）与 `outerGapClosed`（旧档为未涂黑），并允许布局值 0 | 有 |

## 由界面引导、仍由 GM 确认的规则

- 大成功后的生命力或变调回复、命中大成功的追加伤害；
- 神通丸、遁甲符等重投的宣言顺序与连续重投；
- 复数目标、同一布局的同时处理及同一时机效果顺序（同速批次的伤害／逆止／变调由界面暂缓并提示，待全员完成攻击处理后由 GM 统一点选应用）；
- 接近战、射击战、集团战伤害的实际分野或变调选择；
- 感情判定成功后，双方分别掷感情表并各自决定正面或负面；
- 一般人的预测值（暗选 1–6，只能攻击布局等于预测值或为 0 的角色）与其特殊命中／伤害：布局 0 本身已自动处理，预测值与目标限制仍由 GM 把关（后续计划：`ordinaryPerson`／`prediction` 字段与布局栏预测值按钮）；
- 支援忍法、可选多个目标的忍法及【必杀一击】【范围攻击】以布局 0 角色为目标时的距离豁免（界面对单一目标的宣言已自动豁免）；
- 战斗名册与感情战斗乱入：谁参加这场战斗、乱入资格（仅限对最初两名参战者抱有感情）与宣言时机、脱落与战斗结束条件目前由 GM 判断，布局栏仍列出全部参战中角色（后续计划：`battle` 名册对象、可乱入提示与结束检查）；
- 忘却、诅咒、故障、行踪不明、重伤等变调的具体效果（忘却哪条感情、诅咒哪个忍法、故障禁用忍具、行踪不明限制登场、重伤判定后受伤）与巡末回复判定队列：变调栏只记录标签（后续计划：复用麻痹的随机封锁模式）；
- 战场表（水中、高处、恶天候、拥挤、极地）及【镰鼬】等回避修正：调色板只输出 BT 命令名，修正由 GM 手动输入（后续计划：随战斗名册一起记录战场并自动带入修正）；
- 胜者、战果、脱落、奥义破解，以及各忍法或背景的特殊文本。

这些流程会显示检查点和日志，但不会在缺少完整效果文本时擅自替 GM 作出选择。

## 不在“一致性保证”内的内容

- 用户自行录入的自定义忍法、背景、奥义与模组特殊规则；
- 自动 Replay、场景牌桌、局势神谕和“失败也前进”建议；
- 自动角色卡作者 QA 中没有得到官方规则或勘误支持的解释；
- 扩展书全部忍法效果的自动结算。

以上功能都不会暗中修改真实骰点、判定结果、伤害或秘密。界面中的原创主持建议会明确标为灵感或自定义处理。
