# 忍神控制台

面向《忍神 / Shinobigami》线下与线上团务的本地优先辅助工具。从开团公告、PC 分配和角色卡复核，到场景巡次、情报共享、秘密布局和攻击结算，都集中在一个无需账号的网页里，同时保留 GM 的最终裁定权。

> 非官方二次创作工具。本仓库不包含规则书、模组正文、字幕原文或完整忍法资料；使用时仍需合法持有原作资料。

## v0.4 功能

- 开团门禁：集中记录规制、类型、人数、巡数、阶级、新卡/续卡、允许扩展、交卡期限与可调整的角色卡检查值。
- 私密 PC 位：分开保存公开使命和私人秘密，跟踪“秘密已送达、问题已答复、GM 已复核”三项状态，并可安全同步到角色卡。
- 智能体检：检查人数、PC 分配、秘密送达、卡片复核、使命、基础接近战攻击、特技数、忍法槽和忍具数；硬阻塞与可由 GM 确认的数量提醒分开处理。
- 攻击流水线：忍法宣言后依次进入命中判定、同一时机宣言窗口、回避判定、效果结算和完成；未完成时阻止误切行动者或新回合。
- 同速提醒：同一布局存在多名角色时，提醒先暂存结果、待同速角色完成攻击后统一应用生命、逆止、变调和附带效果。
- 安全迁移：旧 v0.3 本地存档与 JSON 会迁移到带 `schemaVersion: 4` 的新结构；异常存档在进入界面前被拒绝或补齐安全默认值。
- 隐私增强：桌面安全模式同时隐藏角色秘密、PC 私密栏、主持事件、场景摘要和团务日志。
- 既有能力：场景导演、巡次与行动、主持事件、进度条、定向感情、非连锁情报共享、精确 2D6 概率、特技代用、秘密布局、距离/花费检查、纯文字角色卡导入、撤销和本地 JSON 存档。

## 本地资料如何影响本版

- 六个用户提供的 SRT 经哈希检查后内容完全相同，实际仅是一段开团准备与车卡教学。v0.4 因此只把它作为“公告 → PC 分配 → 私发秘密 → 依据秘密构筑 → GM 复核”的产品证据，不声称从中观察到了三巡或高潮实跑。
- 本地压缩包中最新的简/繁 v1.51 规则书用于核对巡/场景、宣言时机、攻击顺序、同速延迟结算和情报边界。工具只实现流程校验，没有复制规则原文或完整资料表。

## 数据与隐私

- 团务数据默认只保存在当前浏览器的本地存储中。
- 纯文字角色卡在浏览器内解析，不会上传到外部服务。
- “桌面安全”用于临时共享屏幕，不等同于多人权限系统；JSON 存档仍可能包含秘密、奥义和主持信息，请按敏感文件保管。
- 特殊忍法、扩展规则和剧情冲突仍以 GM 与所用版本规则书为准。
